About this agent: it is a multi-agent system. workflow.py is frozen framework glue that only calls mas_workflow.run_task(task); mas_workflow.py runs the roles — Flight and Train each on the task alone, then Sightseeing given their messages, then Accounting given Sightseeing's — and decides which upstream messages each role receives. Each role lives in agents/<role>.py (its system prompt, the tools it may call, its control flow); agents/common.py holds what every role shares (the bounded tool-calling loop, shared rule text); agents/llm_backbone.py reads mas_llm_backbone.yaml, the per-role backbone LLM settings. Roles exchange the frozen AgentMessage of agents/immutable/message.py (sender, content, ok, iterations, budget_exhausted, error, output_truncated): the contract cannot change, what each stage puts into it can. mas_workflow.run_task(task) must keep that exact signature.
