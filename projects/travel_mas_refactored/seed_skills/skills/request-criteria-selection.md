# request-criteria-selection

**When:** you are choosing which flight or train to book.

**Steps**
1. List every criterion the traveler stated for this leg: direct vs transfer, earliest / latest departure or arrival,
   cheapest, shortest journey, seat class, carrier or aircraft maker, time window.
2. Query with the filters the tool supports (e.g. seat class), then filter the results by the remaining criteria.
3. Among the options that satisfy ALL stated criteria, pick the one that best matches the ordering criterion
   (earliest/latest/cheapest/shortest). Only if none satisfies them all, relax the least important one and say which.
4. Copy times, stations/airports, number and price exactly from the chosen tool result.

**Check:** for the booked option, state in one line how it meets each listed criterion.
