# budget-arithmetic-check

**When:** you are writing the budget summary.

**Steps**
1. List every priced line in the itinerary by category: intercity (per person), city transport (per vehicle/trip),
   accommodation (per room per night), meals (per person), attraction tickets (per person).
2. Multiply by the right count: per-person items x travelers; rooms x nights for hotels; city trips as priced.
3. Add each category, then the total; recompute each sum a second time from the list and make sure both agree.
4. Use only prices that appear in the itinerary; never introduce a new price.

**Check:** category sums add up to the total, and every term in each sum maps to one itinerary line.
